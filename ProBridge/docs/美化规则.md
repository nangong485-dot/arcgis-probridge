# 专题图美化规则（含 Pro 落地对应表）

> 来源：Imhof《Cartographic Relief Presentation》的色晕（hypsometric tint）传统、
> 国际百万分一世界地图（IMW）高程色、Tom Patterson & Bernhard Jenny
> *The Development and Rationale of Cross-blended Hypsometric Tints*（Cartographic
> Perspectives 69, 2011），以及本机 Pro 3.5 实测。数字是**出图验收阈值**，不是美学偏好。

## 一、地形底图（色晕 + 晕渲）

| # | 规则 | 阈值 / 参数 |
|---|------|------------|
| 1 | 高程色晕以明度编码：整体由低到高变亮，峰顶为全带最亮；允许山地棕/灰带局部变暗，但暗带不能压掉晕渲 | 全带 L* 跨度 ≥ 20（本带 max−min = 34.0，首尾差 25.6）；相邻档 \|ΔL*\| ≤ 25（本带最大 20.5）；峰顶 L* 为全带最高 |
| 2 | 色相顺序：低地绿 → 丘陵黄绿 → 山地黄棕 → 高山灰 → 峰顶白 | 相邻色相角差 ≤ 50°（本带最大 44.6°，低地绿→黄绿）；白/灰端不参与色相角检查 |
| 3 | 底图低饱和，给专题色让路 | 低地至山地 S = 0.12~0.36（本带 0.168~0.355）；雪线/灰带允许 S < 0.12（本带 0.036~0），属有意中性高光。专题面覆盖处，底图与专题面明度差 ≥ 35/255；棕带重叠时加透明度或降饱和 |
| 4 | 高程拉伸用分位数，不用 min/max | 0.5% ~ 99.8%（否则出现白色噪点斑） |
| 5 | 晕渲参数 | 光照方位 315°（西北）、高度角 45°、z-factor 2~3（平原区） |
| 6 | 晕渲与色晕的混合 | 相乘混合，明暗系数控制在 0.85~1.15，均值 1.0（不要整体压暗） |
| 7 | 底图不留白边 | 研究区外填白或透明，不给灰底 |

参考色带（可直接照抄，`ProBridge/tools/make_relief.py` 里就是这套）：

```
0.00 #9FBFA3   0.15 #BCD19A   0.28 #D9DFA6   0.42 #EDE3B0
0.55 #E2C99B   0.68 #CBA983   0.80 #B49C8C   0.92 #DCD8D4   1.00 #FFFFFF
```

注：L* 为 CIELAB 明度（0–100）；本文所有 L* 阈值均按 0–100 计，不要与 0–255 的 sRGB 值混用。

## 二、专题要素

| # | 规则 | 阈值 / 参数 |
|---|------|------------|
| 8 | 面要素填充饱和要高过底图 | S ≥ 0.45，与底图亮度差 ≥ 35/255 |
| 9 | 分级色带用同一色相族或**双变量**（色相+明度），不用彩虹 | 默认 3~7 类（5 级最稳）；相邻级 \|ΔL*\| ≥ 8（5 级 YlOrRd 约 14~16，6/7 级下限约 8.5）；全阶 L* 跨度 ≥ 35（3 级约 39.8，5 级约 58.9）；8~12 级必须提供 ≥ 级数的显式 `colors[]`，并逐级检查明度差 |
| 10 | 线宽按印刷 300dpi 给 | 0.4~1.0 pt；主/次线宽比 ≥ 1.8:1 |
| 11 | 边界线要与底图区分 | 深灰（#3C3C3C）或深红（#B02A2A），宽度 0.6~0.9 pt |
| 12 | 点符号 | 直径 3~8 pt，最小 ≥ 2 pt；同级符号尺寸差 ≤ 1.5 倍 |
| 13 | 注记 | 正文 8~10 pt，类名 9~12 pt，必须加 0.6~1 pt 白色晕圈（Halo） |
| 14 | 色盲安全 | 不靠红绿传达等级；相邻级 \|ΔL*\| ≥ 8、全阶 ≥ 35；优先蓝-橙/黄-蓝组合；小字号或低质量打印建议相邻 ≥ 12 并优先 5 级；用 Color Oracle / Coblis 模拟验收 |

## 四、在 ArcGIS Pro 里怎么落地

| 目标 | 操作路径（Pro 3.5） |
|------|---------------------|
| 色晕色带 | 图层属性 → 符号系统 → 拉伸 → 色带。内置 **512 套**，高程类 `Elevation #1 ~ #12`、海底 `Bathymetry #1~#5` |
| 高程拉伸 | 同一面板 → 拉伸类型 = 百分比截断，下限 0.5 / 上限 99.8 |
| 晕渲 | 同面板 → 勾"晕渲"，方位 315°、高度角 45°、z-factor 2~3；进阶可用 山体阴影 + 乘法混合 |
| 面要素透明 | 符号系统 → 填充颜色 α ≤ 70%，或多个面叠加时用"色带 + 透明度"避免糊 |
| 文字晕圈 | 标注属性 → 符号 → 晕圈，颜色白、大小 0.8 pt |
| 图廓双线 | 插入 → 布局元素 → 矩形，叠两条：外 1 pt 黑、内 0.4 pt 黑，间距 1.5 mm |
| 比例尺/指北针 | 插入 → 比例尺 / 指北针，样式选"交替比例尺"/"ESRI 北箭头 1" |

## 五、实测踩坑（都验证过，别再踩）

1. **烘焙好的 RGB 三波段进 Pro 会被"显示时拉伸"整体改色相**（浅绿变青、黄棕变灰）。实测：即便把每个波段都拉到 0–255、并改用 PIL 写干净的 TIFF + `.tfw`，Pro 3.5 仍然改色。**对策：把"拉伸类型"设为「无」**。v0.2.0 起可脚本化：`python client/cli.py symbology <图层> --kind raster_stretch --stretch none`。更省事的做法是干脆不烘焙 RGB，让 DEM 直接吃色带（`--colors ...` 那一条命令），色带和图例都还能改。
2. **`SaveToLayerFile` 对栅格图层在 Pro 3.5 返回空壳**（75 字节的 `CIMLayerDocument`），按钮"另存为图层文件"必须走 Pro GUI。
3. **`ApplySymbologyFromLayer` 在 Python 里跑完不刷新地图**（Esri BUG-000108497），要 `updateConnectionProperties` 或重开一次图层。
4. **桥 0.1.0 的 `set_layer_render(mode="rgb")` 会把三波段画成全黑**，`stretch` 只能给单波段灰度；改符号目前只能靠"Pro GUI 调好 → 存 .lyrx → add_layer 复用"。
5. **`add_layer` 插到图层树顶部**：底图必须**先**加，边界/专题**后**加，否则被盖住。
6. 工程里 `pb_` 前缀的临时图层记得清：`client\cli.py clear pb_`（或逐个 `remove-layer`）。

## 六、分级设色与点符号（开源依据）

| # | 规则 | 出处 |
|---|------|------|
| 21 | 顺序型数据（密度、百分比、量级）用**明度主导的顺序色阶**：单色相或多色相均可（如 YlOrRd、YlGnBu），浅→深；不要彩虹色 | ColorBrewer / Axis Maps「Using Colors on Maps」/ Hands-On Data Visualization「Design a choropleth map」 |
| 22 | 分级方法按数据分布选：偏态用**自然断点（Jenks）**；要让每级区县数量相当用**分位数**；数据本身有规范阈值时用**手工断点** | PSU GEOG 486「Data Classification」/ QGIS Training Manual |
| 23 | 分级数 3~7 级；5 级是最常见的折中（图例可读 vs 差异可见） | Cartography Guide（Axis Maps）、ColorBrewer |
| 24 | 顺序色阶取 ColorBrewer 的 5 级 `YlOrRd`：`#FFFFB2 #FECC5C #FD8D3C #F03B20 #BD0026` | colorbrewer2.org |
| 25 | 点符号压在深色底图上必须加**白色晕圈**（0.8~1.2 pt），否则糊成一片 | 地图制图学惯例 / Cartography Guide「Symbolization」 |
| 26 | 点大小 5~8 pt；同一张图上只有一类点时用深灰 `#333333`，不要用纯黑 | ArcGIS Pro「Symbols」帮助 + 视觉层级惯例 |

分级设色落地：`client\cli.py symbology <图层> --kind feature_breaks --field <数值字段> --classes 5 --method natural --colors ...`，
断点、各级标签、颜色都会回显（`breaks[]`），便于核对。

## 七、图例与比例尺（实测结论）

- 图例正文 7 pt、图层名 7.5 pt、标题 9 pt；分级设色要**关掉字段名标题**（否则图例里出现 `BUI_PCT` 这种字段名）。
- 分级渲染器**不要再挂 ColorRamp**：挂了会在图例里多出一块与分级无关的空色块。
- 比例尺总长 40~60 mm，4~5 段，端点标 `km`。
- 图例放右侧留白里（不压图），色块 7.5×3.2 mm；图例整列宽 ≤ 图宽 1/5（见规则 19）。

## 八、桥的能力边界（v0.3 现状）

- 能做（全部脚本化）：加/删图层、缩放、建布局、绑图框、改文字、导图、跑 GP/arcpy、**改符号**（栅格色带/拉伸/RGB、要素填充/描边、点符号、分级设色）、**加比例尺/指北针/图例**。
- 仍不能做：改图层顺序（只能靠"后加的在上"）、删布局、手工排序图例项、色带式（栅格连续）图例。
- 图例项顺序跟图层顺序走（自下而上），要多控制就得在 Pro 里手工拖。

## 九、踩坑（新增）

7. **Pro 自带比例尺默认英里且改不动**：`CIMScaleBar.Units` 无公开可赋值类型，`SetDefinition` 只收 `CIMElement`。`add_surrounds` 因此按 `frame.Camera.Scale` 自绘公制比例尺（1 mm = 分母/1000 米）。
8. **图例字号要显式压**：`Legend.GetDefinition()` 取 `CIMLegend` → 改 `Items[].LabelSymbol/LayerNameSymbol` → `legend.SetDefinition((CIMElement)(object)lg)` 写回；不写显式转型编译不过。
9. **`Aggregate` / `CheckInExtension` 会让 arcpy 进程静默崩溃**（`0xC0000005`，exit 1 无 traceback）：密度图默认 `--agg 50`，并去掉 `CheckInExtension`。
